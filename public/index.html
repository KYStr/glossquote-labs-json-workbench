如何檢查與整理 JSON

貼入 JSON，確認語法與重複鍵檢查後，複製更容易閱讀的排版。大型整數和小數的原始文字寫法會保留，但不代表所有下游軟體都支援相同精度。

  1. 貼上 JSON 原文，選擇「兩空格排版」或「壓成一行」。
  2. 按「檢查並整理」。若錯誤有位置，按「前往錯誤位置」移動插入點，再自行修正並重新檢查；原文不會自動變更。
  3. 複製整理結果，或下載 UTF-8、無 BOM 的 formatted.json。
大小、結構與互通性限制
  • 輸入最多 262,144 UTF-8 bytes（256 KiB），先檢查 UTF-16 長度不超過 262,144。
  • 最多 50,000 個 token（含標點、不含空白），容器巢狀最多 64 層。
  • 單一字串原文含引號最多 65,536 UTF-16 code units；數字最多 4,096。
  • 輸出最多 4,194,304 UTF-8 bytes（4 MiB），處理上限 5 秒；超限不產生部分結果。
  • 只接受一個完整 JSON value，包含字串、數字、布林與 null。拒絕註解、尾逗號、BOM、重複鍵與未配對的 Unicode surrogate。

錯誤的行與欄從 1 開始，offset 從 0 開始；欄以 UTF-16 code units 計算，CRLF 算一次換行。沒有 schema 驗證、JSON5 或自動修復功能。

常見問題

會改變很長的數字嗎？

只調整 token 之間的空白，不先轉為 JavaScript Number，所以數字原始字面會保留，包括 -0、1.2300、1e400 與大型整數。原文保留不代表下游軟體也能精確使用它們。

為什麼重複鍵不能格式化？

不同軟體可能只保留一筆或採不同結果；此工具會停止處理，請先明確選定來源。鍵以解碼後的字串精確比較，不改大小寫、不去空白或做 Unicode 正規化。

支援註解或尾逗號嗎？

不支援。本工具只接受限制範圍內的嚴格 JSON，不會自動猜修復方式。

我的 JSON 會被保存嗎？

工具只在本次頁面記憶體處理；重新載入不主動恢復內容，來源與結果不寫入網址或瀏覽器儲存空間。網站載入仍需取得 HTML、CSS 與程式資源；工作內容不送往處理伺服器。

「全部清除」移除本頁持有的內容、停止工作並恢復預設模式，不能撤回已下載檔案、既有剪貼簿或抹除底層實體記憶體。載入完成後可離線處理；關閉後離線重新開啟未提供保證。
